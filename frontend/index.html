🛠️ Hardware Setup Guide: Connecting Soil Moisture Sensor, NPK Sensor & Pump Relay to ESP32

Required Components: ESP32 Microcontroller (or Arduino UNO + ESP8266), Capacitive Soil Moisture Sensor v1.2 (Analog Pin A0), RS485 NPK Soil Sensor (MAX485 module to Serial2 RX2/TX2), 5V Single-Channel Relay Module (Pin D7), and 12V/220V Water Pump.

Arduino / ESP32 Code Sketch (Sends Telemetry via HTTP POST):

#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
const char* serverUrl = "http://YOUR_PC_IP:5000/api/sensors/telemetry";

#define MOISTURE_PIN 36 // ADC1_CH0 (VP)
#define RELAY_PIN 23    // GPIO connected to Relay IN

void loop() {
  int rawValue = analogRead(MOISTURE_PIN);
  float moisturePct = map(rawValue, 3200, 1400, 0, 100); // Calibrated Dry vs Wet
  
  HTTPClient http;
  http.begin(serverUrl);
  http.addHeader("Content-Type", "application/json");
  String payload = "{\"soil_moisture_pct\":" + String(moisturePct) + "}";
  int httpCode = http.POST(payload);
  http.end();
  delay(15000); // Send every 15 seconds
}

Automated Pump Relay Control: The web app can toggle the pump relay directly by calling POST /api/irrigation/pump-control with {"state": "ON"|"OFF"}.
